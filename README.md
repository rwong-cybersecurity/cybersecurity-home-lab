# 🛡️ Cybersecurity Home Lab

A hands-on cybersecurity laboratory built to develop practical skills in security monitoring, log analysis, threat detection, incident investigation and incident response.

## 🎯 Objectives

This lab is designed to develop practical experience with:

* Windows security monitoring
* Linux fundamentals
* Network security
* Windows Event Logs
* Sysmon
* SIEM concepts
* Microsoft Sentinel
* KQL
* Threat detection
* Incident investigation
* Incident response
* Security documentation
